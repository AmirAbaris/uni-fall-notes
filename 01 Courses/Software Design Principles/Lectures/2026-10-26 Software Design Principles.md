# Software Design Principles

## Main ideas
- The semester presentation is a cumulative project: keep one subject and extend it as new weekly requirements are assigned.
- Current presentation deliverables: select a subject, create an organizational chart (نمودار سازمانی), and create a DFD.
- The selected project is Weeto, a Persian-first interview scheduling system. The completed subject, proposed organization chart, and DFD are collected in [[01 Courses/Software Design Principles/Assignments/Semester Presentation Project|Semester Presentation Project — Weeto]].

## Definitions and formulas
- **Organizational chart (نمودار سازمانی):** shows company roles/functions and reporting relationships. For this project it is a proposed Weeto company structure inspired by Cal.com's publicly described functional groups; it is not a software component diagram.
- **DFD (Data-Flow Diagram):** shows external entities, processes, data stores, and data flows. The assignment note contains a context diagram (Level 0) and booking process diagram (Level 1).

## Examples
- Weeto's Level 1 DFD traces public slot discovery and booking through PostgreSQL, optional Google Calendar/Meet, and the email outbox worker.
